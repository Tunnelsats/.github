# Tunnel⚡Sats

**Hybrid connectivity for Lightning Nodes. No KYC. No Logs.**

TunnelSats provides pre-configured WireGuard VPN tunnels designed specifically for Bitcoin Lightning Node operators. We enable you to run your node in **Hybrid Mode** (Clearnet + Tor) to improve routing reliability and speed while keeping your home IP address private.

### ⚡ Key Features
* **Privacy First:** No KYC, no logs, and payments via Lightning Network only.
* **Hybrid Connectivity:** Hide your home IP behind our high-performance VPS endpoints while maintaining Tor connectivity.
* **Split-Tunneling:** Intelligent routing separates Lightning P2P traffic (VPN) from other traffic.
* **Automation:** Simplified setup scripts for RaspiBlitz, Umbrel, and bare metal Linux systems.
* **Global Reach:** Low-latency endpoints in the USA, Europe, Asia, South America, and Australia.

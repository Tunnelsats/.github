## 🐛 Reporting Bugs

Before opening a GitHub Issue, please:
1. Run `sudo tunnelsats verify` (on bare-metal, RaspiBlitz, or myNode) or check the in-app status diagnostics (on Umbrel or StartOS).
2. Redact your WireGuard `PrivateKey`, `PresharedKey`, and node macaroon/NWC secrets before pasting any logs or `.conf` files.
3. Open an issue in the relevant repository:
   - Core CLI & Managed Mode (`tunnelsats.sh`): [Tunnelsats/tunnelsats/issues](https://github.com/Tunnelsats/tunnelsats/issues)
   - Umbrel App & `k3s`: [Tunnelsats/ts-umbrel-app/issues](https://github.com/Tunnelsats/ts-umbrel-app/issues)
   - StartOS Package: [Tunnelsats/tunnelsats-startos/issues](https://github.com/Tunnelsats/tunnelsats-startos/issues)
   - myNode BTC App: [Tunnelsats/ts-mynode/issues](https://github.com/Tunnelsats/ts-mynode/issues)
   - Nostr Community Bot: [Tunnelsats/nostr-community-bot/issues](https://github.com/Tunnelsats/nostr-community-bot/issues)
